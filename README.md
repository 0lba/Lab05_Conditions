## Краткое описание работы
Освоил конструкции if/else, switch/case и тернарный оператор. Разобрал вложенные условия и логические операторы (&&, ||, !). Написал программу «Угадай число» - игру, в которой все условные конструкции используются естественным образом.
## Структура проекта
```csharp
string GetHint(int difference) {
    switch (difference) {
        case <= 3:
            return "🔥 Горячо!";
        case <= 10:
            return "🌡️ Тепло.";
        case <= 25:
            return "🌀 Прохладно.";
        default:
            return "❄️ Холодно!";
    }
}
```

2. switch удобнее, когда одна переменная сравнивается с конкретными значениями.Пример:
```csharp

        break;
    default:
        Console.WriteLine($"Ошибка: пункт <{choice}> не существует. Введите число от 1 до 4.");
        break;
}
```
